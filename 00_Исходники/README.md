# Исходные материалы

Файлы автора проекта. Переименованы в читаемые названия; содержимое не изменялось.

## Приквел — «Лисица Кибелы и геомагнитная бабочка»

Короткометражный фильм, 20–22 мин., научный триллер. Москва, Тропарёво, за три года до событий полного метра.

| Файл | Что это |
|---|---|
| `Приквел_Лисица_Кибелы_сценарий_v3.docx` | Сценарий, актуальная версия |
| `Приквел_Лисица_Кибелы_сценарий_v3.pdf` | То же в PDF, 18 стр., с техническими примечаниями для съёмочной группы |
| `Приквел_Лисица_Кибелы_сценарий_v2.txt` | Предыдущая версия, для сверки правок |
| `Приквел_Лисица_Кибелы_питч-дек.pdf` | Питч-дек, 5 стр.: логлайн, концепция, синопсис по актам, герои, жанровые маркеры |

## Соответствие версий

- Приквел существует в трёх видах: v2 (txt), v3 (docx и pdf). **Рабочая версия — v3.**
- PDF приквела содержит блок технических примечаний (локации, флешбэки, реквизит, спецэффекты), которого нет в более ранних версиях.
- Полный метр — одна версия, с ремарками о научной базе и эпилогом.
