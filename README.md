## Ключевые цифры

| | |
|---|---|
| Серия 18–20 мин, рекомендуемый тир B | **2,6–3,2 млн ₽** |
| Сезон 8 серий с учётом сетапа | **30,6 млн ₽** |
| Пилотная серия (тир A+) | **1,2 млн ₽** |
| Вход в проект до стороннего финансирования | **1,95 млн ₽** |
| Типовая интеграция бренда на рынке РФ | 3–7 млн ₽ |
| Нужно интеграций, чтобы закрыть сезон | **5–7** |
| Потенциал гранта ИРИ | 10–40 млн ₽ |

**Экономика:** 5–7 интеграций по 3–7 млн ₽ дают 15–49 млн ₽ при стоимости сезона 30,6 млн ₽. Product placement здесь — не приятное дополнение, а основной механизм финансирования.

## Как пользоваться одностраничниками

1. Открыть `05_onepagers/index.html` в браузере
2. Выбрать компанию
3. Ctrl/Cmd + P → «Сохранить как PDF» → размер A4, поля «нет», фоновая графика «вкл.»
4. Приложить PDF к письму из `04_letters/`

Чтобы поправить содержание — редактировать `05_onepagers/build.py` (список `COMPANIES` внизу файла) и запустить `python3 build.py`.
