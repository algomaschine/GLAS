# Исходные материалы

Файлы автора проекта. Переименованы из служебных имён системы загрузки в читаемые; содержимое не изменялось.

## Приквел — «Лисица Кибелы и геомагнитная бабочка»

Короткометражный фильм, 20–22 мин., научный триллер. Москва, Тропарёво, за три года до событий полного метра.

| Файл | Что это |
|---|---|
| `prikvel_scenariy_v3.docx` | Сценарий, актуальная версия v3 |
| `prikvel_scenariy_v3.pdf` | То же в PDF, 18 стр., с техническими примечаниями для съёмочной группы |
| `prikvel_scenariy_v2.txt` | Предыдущая версия v2, для сверки правок |
| `prikvel_pitch_deck.pdf` | Питч-дек, 5 стр.: логлайн, концепция, синопсис по актам, герои, жанровые маркеры |

## Полный метр — «Проект ГЛАС»

## Соответствие версий

- Приквел существует в трёх видах: v2 (txt), v3 (docx и pdf). **Рабочая версия — v3.**
- PDF приквела содержит блок технических примечаний (локации, флешбэки, реквизит, спецэффекты), которого нет в более ранних версиях.
- Полный метр — одна версия, full v3, с ремарками о научной базе и эпилогом.
